# Orbit CRM

Русскоязычная локальная CRM на Node.js без внешних зависимостей.

## Запуск

Требуется Node.js 22 или новее. Устанавливать npm-пакеты не нужно.

```sh
npm start
```

Откройте http://localhost:3000. Для разработки с перезапуском сервера: `npm run dev`.
Другой порт в PowerShell: `$env:PORT = '3001'`, затем `npm start`.
Если PowerShell блокирует `npm.ps1`, используйте `npm.cmd start` и `npm.cmd test`.

## Структура

```text
index.js                    Запуск сервера
server/
  app.js                    HTTP-сервер и обработка ошибок
  config.js                 Этапы продаж и команда
  routes/
    api.js                  Маршруты клиентов, сделок, задач, настроек
    static.js               Раздача файлов public/
  data/
    store.js                Чтение и атомарная запись JSON
    seed.js                 Начальные демонстрационные записи
  services/backup.js        Проверка и восстановление резервной копии
  validation/records.js     Правила проверки данных
  utils/                    Ошибки и чтение JSON-запросов
public/
  index.html                HTML и порядок подключения скриптов
  css/
    styles.css              Базовые стили и подключения
    layout.css              Навигация, шапка, каркас
    components.css          Формы, таблицы, диалоги, кнопки
    pages.css               Стили отдельных экранов
    responsive.css          Адаптация к размерам экрана
  js/
    app.js                  Загрузка приложения
    core.js                 Состояние, API, форматирование, иконки
    layout.js               Каркас и переключение экранов
    events.js               Обработчики форм, поиска, drag-and-drop
    export.js               CSV-экспорт
    components/             Диалоги, графики, статистика, фильтры
    pages/                  Обзор, сделки, клиенты, задачи, аналитика, настройки
tests/api.test.js           Интеграционные тесты
data/crm.json               Данные; создаётся при первом запуске
```

Сервер использует CommonJS-модули. Скрипты интерфейса подключаются с `defer` в порядке из `public/index.html` и используют общее состояние из `core.js`; сборщик не требуется. Новый экран добавляется в `public/js/pages/`, затем подключается в HTML и маршрутизаторе `layout.js`.

## Возможности

- Создание, редактирование и удаление клиентов, сделок и задач.
- Канбан с перетаскиванием, табличный вид, фильтры и поиск.
- Карточка клиента со связанными сделками и задачами.
- Приоритеты, сроки и завершение задач.
- Динамика выручки, воронка, показатели команды и месячный план.
- Настройки профиля, компании, валюты и плана.
- CSV-экспорт клиентов и сделок; JSON-копии и восстановление.
- История изменений, подтверждения удаления, проверка данных на сервере.

При первом запуске создаются демонстрационные данные. Все изменения сохраняются в `data/crm.json`. Резервные копии доступны в настройках. Смена валюты меняет обозначение сумм, а не курс.

Это однопользовательское локальное приложение: сервер слушает только `127.0.0.1`, без авторизации, почтовых интеграций и совместного доступа. Для командной интернет-версии потребуются отдельная база данных, пользователи и права доступа. Не запускайте несколько серверов с одним файлом данных одновременно.

## Проверки

```sh
npm test
```

Тесты используют отдельные временные файлы и не изменяют рабочие данные. Проверяются жизненный цикл записей, связи между сущностями, сохранение после перезапуска, валидация, восстановление копии и доступность статических файлов.
